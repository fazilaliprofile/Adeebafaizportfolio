# Adeeba Faiz — Portfolio

Static portfolio website (HTML + CSS, no build step). Layout follows the same structure as the `arhamfaizportfolio` site.

## Sections
Hero · Projects & Creative Work · About Me · Education · Internship Experience · Skills & Tools · Contact

## Files
- `index.html` — all content; every `[bracketed]` text is a placeholder to replace
- `styles.css` — colours and theme are the variables at the top of the file

## Adding work
Replace a `<div class="ph">…</div>` tile with
`<a href="file.jpg" target="_blank" rel="noreferrer"><img loading="lazy" src="file.jpg" alt="…"></a>`
and put the image file in this folder.

## Deploy
Hosted on Vercel (`adeebafaizportfolio.vercel.app`).
