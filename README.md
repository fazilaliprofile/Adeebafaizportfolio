# Adeeba Faiz — Portfolio

Static portfolio website (HTML + CSS, no build step). Layout follows the same section format as the `arhamfaizportfolio` site.

## Sections
Hero · Projects & Creative Work · About Me · Education · Internship Experience · Experience Highlights · Core Skills · Career Objective · Contact

## Files
- `index.html` — all content (taken from Adeeba's CV)
- `styles.css` — colours and theme are the variables at the top of the file

## Adding creative work later
The Projects section uses placeholder tiles. Replace each `<div class="ph">…</div>` with
`<a href="file.jpg" target="_blank" rel="noreferrer"><img loading="lazy" src="file.jpg" alt="…"></a>`
inside a `.poster-grid`, and put the image files in this folder.

## Deploy
Hosted on Vercel (`adeebafaizportfolio.vercel.app`).
