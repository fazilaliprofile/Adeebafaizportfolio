# Adeeba Faiz — Portfolio

Static portfolio website (HTML, CSS, JS). No build step.

## Files
- `index.html` — page content (replace the placeholder text and links)
- `styles.css` — design (colors are CSS variables at the top)
- `script.js` — mobile menu and scroll animations

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy
Connected to Vercel; every push to `main` redeploys automatically.
