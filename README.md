# Adeeba Faiz — Portfolio

Static portfolio website (HTML + CSS, no build step). Layout follows the same section format as the `arhamfaizportfolio` site.

## Sections
Hero · Projects (MJ Marketing Consultancy, Ascend) · Work Certificates (MJ Marketing, Ascend, Aeon Pharma) · About Me · Education · Internship Experience · Experience Highlights · Core Skills · Career Objective · Contact

## Files
- `index.html` — all content (taken from Adeeba's CV)
- `script.js` — scroll progress bar, active nav link, scroll reveal and 3D card tilt (mouse devices only)
- `styles.css` — colours and theme are the variables at the top of the file

## Deploy
Hosted on Vercel (`adeebafaizportfolio.vercel.app`).
